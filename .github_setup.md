# Push this to GitHub

The repo is already initialized with one commit. Pick either:

## With the GitHub CLI (fastest)
    gh repo create mr-chile-taproom --public --source=. --push

## With plain git
Create an empty repo at github.com/new named `mr-chile-taproom` (no README,
no .gitignore, no license), then:

    git remote add origin git@github.com:YOUR_USERNAME/mr-chile-taproom.git
    git push -u origin main

Then send me the `owner/name` and I'll link it to Vercel so every push
auto-deploys.
